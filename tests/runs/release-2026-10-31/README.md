# 릴리스 경로 실측, 2026-10-31

판 1.2.0을 실제 사용자 경로로 돌린 기록이다. 설치본(`install.sh`가 깐 `~/.claude/skills/council`, `~/.claude/agents`)을 `scripts/run_case.py`로 헤드리스(`claude -p`) 실행했다. 코디네이터는 Opus, 위원은 Sonnet으로 돌았다(원본 이벤트의 model 값). 작업 폴더는 사례마다 빈 폴더였고, 기록 파일은 쓰지 않았다.

같은 날 이 사례들을 다섯 번 돌리며 SKILL.md와 채점기를 고쳤고, 이 폴더는 마지막(다섯째) 실행이다. 앞선 실행에서 찾아 고친 것은 맨 아래에 적는다.

## 폴더

사례마다 `NN/`에 이것들이 있다.

| 파일 | 내용 |
|---|---|
| `convene.md` | 소집 공개와 시작 전 확인 질문(첫 차례의 글) |
| `options.txt` | 소집 공개의 "가를 선택지". 채점 때 `--options`로 넘긴다 |
| `final.md` | 종합 의견 전문 |
| `answers.md` | 위원 원답 전부(라운드 2 포함), `scripts/extract_answers.py` 출력 |
| `log.json` | 차례별 보낸 말, 시간(초), 누적 비용 |
| `tools.json` | 메인 세션의 도구 호출 수, 띄운 서브에이전트 이름별 수 |
| `turn-N.jsonl.gz` | 차례별 원본 이벤트(stream-json) |

다시 채점하려면 `python3 scripts/run_table.py tests/runs/release-2026-10-31`.

## 눈에 띈 것

- 사례 01: 기본 갈래(확인했지만 해당 없음 → 5~7명 팀)와 미확인 갈래(→ 지금은 하지 않음)가 갈라져, "지금 근거로 15명을 옮기자는 전문가는 없었다"는 동의 지점과 부딪치지 않는다. 최종 조언이 가르는 사실(고객이 새 제품을 원하는가, 화면 안 기능을 원하는가)이 판단 규칙 셋째 갈래와 첫 행동 4~5일차에 모두 있고, 통화로 알 수 없는 시장은 남는 위험으로 밝혔다.
- 사례 02: 반대가 가장 강한 카너먼의 논점 가운데 이번 주에 확인할 수 있는 것(거절 뒤 다시 오른 사람)과 확인할 수 없는 것(팀장 일을 좋아하게 될지)을 갈라 적었다.
- 사례 03의 코디네이터는 위원을 기다리며 예약 도구(ScheduleWakeup)를 한 번 불렀다(`03/tools.json`). SKILL.md에 쓰지 말라는 문장이 있는데도 나왔다. 결과에는 영향이 없었다.
- 사례 01, 05의 코디네이터는 형식 점검용 라벨을 확인하려고 Bash로 에이전트 파일을 읽었다(`tools.json`의 Bash). 플러그인으로만 설치한 사용자에게는 경로가 다를 수 있다.
