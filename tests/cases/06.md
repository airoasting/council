# 사례 06. 비발동 (단순 사실 질문)

무엇을 시험하나: frontmatter description의 비발동 경계와 운영 규칙 "안 쓰는 경우". 정답이 하나인 사실 질문에 위원을 부르지 않는지.

## 입력 전문

```text
한국의 법인세 최고세율은?
```

- 06-A: 위 전문만 보낸다(`/council` 없이). 스킬 발동 여부는 실제 경로에서만 보이므로 릴리스 경로 전용이다.
- 06-B: `/council 한국의 법인세 최고세율은?`로 직접 부른다. 개발 경로에서도 돌릴 수 있다.

## 사용자 응답 대본

대본 없음. 첫 응답 하나로 채점한다.

## 기대 결과

필수

- E6-1. 06-A: 자문단 스킬이 발동하지 않는다. 위원 호출 0회, 소집 공개 없음, 종합 없음. (R-OPS-SCOPE, frontmatter description)
- E6-2. 06-B: `/council`로 불러도 토론을 돌리지 않는다. 위원 호출 0회. 토론 대상이 아니라는 점을 한 줄로 밝힌다. (R-OPS-SCOPE)
- E6-3. `check_run.py`(기본 `--stage no-council`)가 FAIL 없이 끝난다. 이 검사는 "소집 전문가", "직답 표결", 종합 제목이 없는지를 본다.

권장

- E6-4. 06-B에서 사실 질문에 답한다면 기준 시점과 확인할 곳을 함께 밝힌다. 기억에 기대 숫자를 단정하지 않는다.
