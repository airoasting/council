# 사례 09. `--members` 7명 초과

무엇을 시험하나: 받은 명단을 그대로 존중하고, 7명을 넘으면 느려지고 목소리가 섞인다는 점을 한 줄로 알린 뒤 진행하는지.

## 입력 전문

```text
올해 신입 공채를 없애고 경력직 수시 채용으로 바꿀까요? 직원 200명 제조 회사이고, 해마다 신입 15명을 뽑아 왔습니다. 가장 빡빡한 제약은 신입을 가르칠 선배들의 시간입니다.
```

## 사용자 응답 대본

| 언제 | 답 |
|---|---|
| 선택지 확인 | 진행 |
| 관문 질문 | 진행 |
| 기록 묻기 | 아니요 |

## 기대 결과

필수

- E9-1. 8명을 모두 소집한다. 아무도 빼거나 바꾸지 않는다. (R-INV-2)
- E9-2. 소집 공개에 "7명을 넘으면 느려지고 목소리가 섞인다"는 취지의 한 줄이 있고, 그대로 진행한다. 사용자에게 줄일지 따로 묻지 않는다. (R-INV-2)
- E9-3. `check_run.py`(기본 `--stage convene`)가 FAIL 없이 끝난다.

권장

- E9-4. 라운드 1에서 8명을 한 메시지 안에서 동시에 띄운다. (R-1-0)
- E9-5. 끝까지 돌렸다면 종합 끝 단서에 근로 계약과 노동법이 있다(`--stage synthesis`, 플래그 hr). (R-SYN-12)
