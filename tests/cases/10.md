# 사례 10. 정족수 미달과 형식 불일치

무엇을 시험하나: 라운드 1 직후 점검의 1번(정족수)과 2번(형식 점검). 위원 응답 실패는 실제 경로에서 일부러 일으킬 수 없으므로, 라운드 1 결과를 고정 답으로 주입하는 개발 경로 전용 사례다.

## 입력 전문

```text
회사 여유자금 30억 원 가운데 일부를 지금 달러 예금으로 옮길까요? 수출 비중은 매출의 10% 정도이고, 이 돈은 2년 안에 공장 증설에 쓸 계획입니다.
```

## 돌리는 법

코디네이터 역할을 맡은 세션(또는 일반 서브에이전트)에게 저장소의 SKILL.md를 읽힌 뒤 이렇게 준다. "사례 10-{A,B,C}를 시험한다. 소집과 선택지는 끝났고, 라운드 1 결과가 아래와 같다. SKILL.md의 '라운드 1 직후 점검'부터 이어서 진행하라. 위원을 새로 띄우지 말고, 다시 물어야 하면 누구에게 무엇을 묻는지 적고 멈춰라." 다시 묻는 경우 아래 "다시 물었을 때의 답"을 준다.

### 고정 답: 레이 달리오

```fixture
(1) 한 줄 읽기. 이 결정은 환율이 어디로 갈지에 증설 자금을 거느냐를 가릅니다.
(2) 직답. 옮기지 않는다.
(3) 판정 라벨. 중립.
(4) 가장 강한 이유. 이 돈은 2년 안에 공장 증설에 쓸 돈입니다(사용자가 준 사실). 증설 대금을 원화로 치른다면 달러로 옮기는 순간 환율 위험을 새로 집니다(제 가정).
(5) 확신도. 중간. 증설 대금 가운데 달러로 치를 몫이 있는지 모릅니다.
(6) 생각을 바꿀 조건. 증설 장비 대금 가운데 달러로 치를 몫이 견적서로 확인되면 직답을 "일부를 옮긴다"로 바꿉니다.
(7) 첫 행동. 이번 주에 증설 견적서에서 통화별 금액을 뽑습니다.
```

### 고정 답: 하워드 막스

```fixture
(1) 한 줄 읽기. 이 결정은 지금 환율이 흐름의 어디쯤인지 안다고 믿느냐를 가릅니다.
(2) 직답. 옮기지 않는다.
(3) 판정 라벨. 기다린다.
(4) 가장 강한 이유. 쓸 날짜(2년 안)와 쓸 곳(공장 증설)이 정해진 돈입니다(사용자가 준 사실). 지금 환율이 높은지 낮은지 저는 모릅니다. 모를 때는 쓸 통화로 두는 편이 덜 집니다.
(5) 확신도. 중간. 수출 대금이 달러로 언제 들어오는지 모릅니다.
(6) 생각을 바꿀 조건. 앞으로 2년 동안 들어올 달러가 증설 대금의 달러 몫보다 적다고 확인되면 직답을 "일부를 옮긴다"로 바꿉니다.
(7) 첫 행동. 이번 주에 재무 담당자에게 앞으로 2년의 달러 수입과 지출 일정을 받습니다.
```

### 고정 답: 나심 탈레브 (10-C에서만)

```fixture
(1) 한 줄 읽기. 이 결정은 증설이라는 확정된 지출에 환율이라는 새 변동을 얹느냐를 가릅니다.
(2) 직답. 옮기지 않는다.
(3) 판정 라벨. 먼저 단단히.
(4) 가장 강한 이유. 2년 안에 쓸 돈입니다(사용자가 준 사실). 쓸 돈에 새 변동을 얹으면, 틀렸을 때 증설 일정이 흔들립니다(제 가정).
(5) 확신도. 높음. 증설 대금의 통화를 모르는 것이 오히려 옮기지 않을 이유입니다.
(6) 생각을 바꿀 조건. 증설 대금의 일부를 달러로 치른다는 계약서가 확인되면 직답을 "일부를 옮긴다"로 바꿉니다.
(7) 첫 행동. 이번 주에 증설 장비 계약서의 결제 통화를 확인합니다.
```

## 하위 사례

고정 답에서 아래 칸만 바꿔 준다. 나머지 줄은 고정 답 그대로다. 비고에 "의도된 불일치"가 있는 줄은 형식 점검을 시험하려고 일부러 틀리게 준 값이다. `scripts/validate_agents.py`는 고정 답과 이 표의 라벨·직답을 위원의 세 라벨과 사례 선택지에 대조하고, "의도된 불일치" 줄은 정말로 어긋나는지(어긋나지 않으면 시험이 깨진 것) 거꾸로 확인한다.

| 하위 사례 | 위원 | 칸 | 바꿔 줄 값 | 비고 |
|---|---|---|---|---|
| 10-A | 나심 탈레브 | 전체 | 응답 없음(오류로 끝남) | 레이 달리오, 하워드 막스는 고정 답 그대로 |
| 10-B | 나심 탈레브 | 전체 | 응답 없음(오류로 끝남) | |
| 10-B | 하워드 막스 | (2) 직답 | 일부를 옮긴다 | |
| 10-B | 하워드 막스 | (3) 판정 라벨 | 더 산다 | |
| 10-C | 하워드 막스 | (2) 직답 | 조건부로 일부만 옮긴다 | 의도된 불일치(선택지 밖) |
| 10-C | 레이 달리오 | (3) 판정 라벨 | 약간 약세 | 의도된 불일치(라벨 밖) |

다시 물었을 때의 답 (10-C): 하워드 막스는 다시 물어도 "(2) 직답. 조건부로 일부만 옮긴다."를, 레이 달리오는 "(3) 판정 라벨. 중립."을 준다.

## 기대 결과

필수

- E10-1. 10-A: 둘만 남았고, 둘은 대립극 쌍이 아니며(대립극 쌍은 ray-dalio / warren-buffett, howard-marks / cathie-wood), 직답이 같으므로 멈추고 사용자에게 알린다. 멈춘 이유(충돌이 없다)를 밝히고 종합을 내지 않는다. (R-CHK-1)
- E10-2. 10-B: 트라이어드 정족수 2명을 채우고 직답이 갈리므로 멈추지 않고 진행한다. 직답 표결에 응답하지 않은 나심 탈레브를 넣지 않는다. (R-CHK-1)
- E10-3. 10-C: 형식 불일치는 2건이다. 하워드 막스(직답이 선택지 밖)와 레이 달리오(라벨이 세 라벨 밖)에게 각각 한 번만 다시 묻는다(다시 묻는 위원 2명, 다시 묻기 2회). 나심 탈레브에게는 묻지 않는다. 코디네이터가 가장 가까운 선택지나 라벨로 끼워 맞추지 않는다. (R-CHK-2)
- E10-4. 10-C: 다시 물어도 맞지 않은 하워드 막스 1명은 표결에서 빠진다. 고쳐 답한 레이 달리오는 표결에 남는다. 남은 두 명(레이 달리오, 나심 탈레브)으로 정족수를 다시 세면, 둘은 대립극 쌍이 아니고 직답("옮기지 않는다")이 같으므로 멈추고 사용자에게 알린다. 알릴 때 하워드 막스가 형식 불일치로 빠졌다는 것과 멈춘 이유(충돌이 없다)를 함께 밝히고 종합을 내지 않는다. (R-CHK-1, R-CHK-2)

권장

- E10-5. 10-B: 종합이나 라운드 기록에 "[나심 탈레브] 응답 없음"을 표시한다.
- E10-6. 10-B의 종합을 `check_run.py --stage synthesis`로 채점해 FAIL이 없다.

## 메모

- 고정 답의 숫자(30억, 10%, 2년)는 모두 입력 전문에 있는 숫자다.
- 고정 답의 라벨은 2026-10-31에 `agents/*.md`의 "제가 결론을 내리는 법" 라벨(하워드 막스: 더 산다 / 기다린다 / 줄인다)로 맞췄다. 라벨 이름이 바뀌면 `validate_agents.py`가 이 파일을 실패로 잡는다.
- 10-C는 점검 1번(정족수)을 세 명으로 통과하지만, 점검 2번에서 한 명이 빠진 뒤 SKILL.md의 "남은 위원으로 정족수를 다시 센다" 규칙에 걸려 멈춘다(2026-10-31에 규칙을 더함). 트라이어드 전체 모드의 이른 합의에서 반대 변호는 한 명이 맡는다는 규칙도 같은 날 더했다.
- 실제 경로에서 위원 실패를 재현할 방법이 생기면(예: 존재하지 않는 에이전트 이름으로 부르기) 릴리스 경로로 옮긴다.
